# Plan configuration

`start_date` is the first day of core slot 1. Setup appears seven days earlier. Extension units have their own order and no dates. Use the [Home dashboard](Home.md) to see the study order and task counts.

To print the core calendar from a terminal, run `python3 tools/plan-dates.py` from the vault root. Use `--start YYYY-MM-DD` to preview a different start.
